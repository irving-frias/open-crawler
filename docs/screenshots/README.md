# Screenshots

Place three screenshots in this directory (referenced by the README table):

| File            | Content                                         |
| --------------- | ----------------------------------------------- |
| `launcher.png`  | Project launcher window (grid of projects)      |
| `results.png`   | Crawl results table with filters                |
| `seo-audit.png` | Site-wide SEO audit panel (scores + categories) |

To capture them:

1. `bun install && bun tauri dev` (or build the release app).
2. Launch the app, create a project and run a crawl against a small site.
3. Take macOS screenshots: `shift-cmd-4` → select the window → saved to the
   desktop. Trim each image so only the app window is visible (no menu bar,
   no window chrome).
4. Name the files exactly as above and drop them here.
